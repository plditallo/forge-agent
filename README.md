# FORGE Agent

FORGE Agent is an AI-powered platform that discovers, evaluates, certifies, and monetizes enterprise data assets.

## Vision

Organizations possess valuable data but often lack visibility into its commercial potential.

FORGE Agent:

- Profiles datasets
- Scores monetization readiness
- Recommends data products
- Generates API opportunities
- Certifies assessments on Casper

## Technology

- Python
- SQL Server
- FastAPI
- React
- Casper Network
- Rust / Odra
